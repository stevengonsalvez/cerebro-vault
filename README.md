# CEREBRO Vault

Obsidian vault for the [CEREBRO](https://github.com/stevengonsalvez/cerebro) daily
tech-signal intelligence pipeline.

| Folder | Contents |
|--------|----------|
| `Daily/` | The daily "explain-to-me" briefing — one note per day. Frontmatter carries `count`, token usage, and cost. |
| `Signals/` | Atomic, Dataview-queryable note per signal. Notes preserve compatibility `tags` plus typed `topic_tags`, `source_tags`, `entity_tags`, `artifact_tags`, and `workflow_tags`. Filename = URL hash → idempotent. |
| `Entities/` | Durable repo and developer profiles, including `Entities/repos/<owner>--<repo>.md` and `Entities/developers/<login>.md`. |
| `Briefs/` | Short research/search briefs that link source signals, GitHub evidence, entities, and next actions. |
| `Watchlist/` | Editable query/entity lists that can feed recurring Cerebro discovery. |
| `Skills/` | Vault-only generated skill bundles such as `Skills/cracked-devs/repos/...` and `Skills/cracked-devs/users/...`; installation is explicit and opt-in. |
| `Inbox/` | Manual capture queue for URLs or topics Cerebro should chase later. |
| `_meta/` | Vault-local metadata. |

Notes are generated by the pipeline. Edit freely — each run only overwrites the current
date's daily note and adds new signal notes by URL hash. The `_scratch/` folder (dry-run
output) is gitignored. No secrets live here.
