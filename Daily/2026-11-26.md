## Coding agents & agent IDEs

- [Orca](https://x.com/Pluvio9yte/status/2125485780072350040): open-source Agent IDE that plugs into your own Claude Code/Codex subscriptions. A lead agent splits work across workers in separate worktrees. Chat and native CLI share one session, and there's a phone remote and Slack/Linear/GitHub bots. Claimed 136k stars since the March open-source release.
- [T3 Code 0.1.12](https://x.com/theo/status/2125706137140166866): projects can now span several repos (a folder of repos, a `.code-workspace` file, or submodules). One worktree branches all of them, so a single turn can change them all.
- [Tendeck](https://www.producthunt.com/products/tendeck): Mac board that runs all your Claude Code and Codex agents in one place. It's another entrant in the agent-dashboard crowd.
- [VibeCode.surf](https://www.producthunt.com/products/vibecode-surf): AI code editor where agents build, run and test your app. The run-and-test loop is the part that matters.
- [CodeRabbit Verify](https://www.producthunt.com/products/coderabbit): agent that tests your running app on every PR. It moves review from reading the diff to exercising the build.

## Agent context, skills & model behaviour

- [Uber's skill management](https://x.com/tirthaexe/status/2125831667721863254): Uber runs 5,000+ agent skills, invoked over 1M times a month. The thread covers how to apply their strategy to your own SKILLs, and it's a useful reference for skill sprawl.
- [Matt Pocock on agent overload](https://x.com/mattpocockuk/status/2125567797656977783): asks when a never-compacted, long-running agent has too many responsibilities and should be split in two. There's no clear heuristic yet, so read the replies.
- [Skirano on "dry mode"](https://x.com/skirano/status/2123524161192743060): run Astra or Sol 6.2 subagents with everything on top of the model disabled. The claim is faster, more efficient operation, so it's worth testing against your harness overhead.
- [Opus 4.5 retirement](https://x.com/StatsWire/status/2125811427562627238): Opus 4.5 goes away on January 22, 2027. Pin or migrate any workflow still on it.

## Agent infrastructure & control layers

- [Vercel Board (Matt Pocock take)](https://x.com/mattpocockuk/status/2124797717834543167): a private Slack-like workspace for your agents and developers, optionally synced to Slack channels for observability. His advice is to build it yourself rather than adopt Vercel's version.
- [OpenEight](https://www.producthunt.com/products/openeight): deterministic control layer for AI agents. It aims to put hard guardrails around non-deterministic models.
- [SteerLatch](https://www.producthunt.com/products/steerlatch): connects MCP-compatible AIs to your computer. It's a generic local-access bridge.

## Personal agents & talks

- [n8n-io/nod](https://github.com/n8n-io/nod): open-source personal agent with its own computer. It chases invoices, preps calls and cancels trials on real websites, and asks before acting. Runs locally with your chosen model on macOS, Windows or Linux.
- [The Revolution vs The Renaissance, Thariq Shihipar (Latent Space)](https://latent.space/p/the_revolution_vs_the_renaissance_thariq_shihipar_openai/): AI Engineer CODE talk arguing cheap software at scale and craft on one polished thing can coexist. The demo edits a fighting game live.
