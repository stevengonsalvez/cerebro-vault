## Prompt caching & context

- [Codex & Work keep cache forever for logged-in users](https://x.com/theo/status/2112713481946570967): Theo calls it the biggest ship of the 28 days; resuming an old conversation no longer costs a cold-cache penalty.
- [12h API cache, unlimited for logged-in users](https://x.com/thsottiaux/status/2112712984644784534): Day 16 post spells out the detail: 12h cache in the API, and logged-in Codex & Work users are guaranteed a cache hit after a few hours away.
- [T3 Code Stable, 1,400+ changes](https://x.com/theo/status/2112741450232508471): Includes beta "idle Claude threads compact early so the cache stays warm", a direct caching trick, plus remote hosts and PR diffs split into code, tests and docs.
- [codex-subscription-router](https://github.com/b-nnett/codex-subscription-router): Spreads new chats across several ChatGPT subscriptions but pins each thread to one account, so follow-up turns keep account-level caching.
- [Graphify](https://github.com/Graphify-Labs/graphify): `/graphify` skill builds a queryable knowledge graph of a codebase via local deterministic AST parsing with no vector store, pitched as an 80% cut in agent token spend.
- [Ponytail](https://github.com/DietrichGebert/ponytail): "Laziest senior dev" skill; its own benchmark (39 tasks, Opus 5.5) claims 45% fewer tokens and 26% lower cost, with more risky logic covered by tests.

## Coding agents & benchmarks

- [SlopCodeBench 10/2026](https://github.com/humanlayer/advanced-context-engineering-for-coding-agents/blob/main/benchmarking-new-models-on-slop-code-bench.md): Opus 5.5 and Astra results; "xhigh considered harmful", and commenters say medium effort is best for most tasks because higher effort mostly adds unrequested output.
- [Devin Fusion scores 68 on Coding Agent Index](https://x.com/ArtificialAnlys/status/2112773422698606736): Opus 5.5 lead plus a GPT-6 Luna sidekick running in parallel beats Claude Code with Opus 5.5 by 2 points at 31% lower cost per task, which supports the lead-plus-cheap-worker pattern.
- [Human-centered coding agents](https://x.com/math_rachel/status/2112375486441816493): Position paper arguing for agents built to collaborate with people rather than run fully autonomously.
- [Claude Code v2.1.306](https://github.com/anthropics/claude-code/releases/tag/v2.1.306): Fixes `claude -p` reporting "Not logged in" in cloud sessions, and a bug where an API error was replaced by "prompt is too long" and triggered needless compaction in sessions with many MCP tools.
- [Claude Code v2.1.305](https://github.com/anthropics/claude-code/releases/tag/v2.1.305): Adds `sandbox.allowNestedUserNamespaces` for Chromium and rootless podman, which also lets sandboxed commands get around the sandbox's file protections, plus `CLAUDE_CODE_RETRY_WATCHDOG_USAGE_LIMIT_RECHECK_MS` for unattended retry mode.
- [Praex](https://www.producthunt.com/products/praex): Product Hunt launch of a coding agent that runs on its own models; there's no detail beyond the tagline.

## Security

- [Using Claude to reduce the attack surface of code](https://www.anthropic.com/research/attack-surface-reduction): Anthropic's early research on using frontier models for defence (automated attack-surface reduction) rather than only finding and exploiting vulnerabilities.
- [cloudflare/security-audit-skill](https://github.com/cloudflare/security-audit-skill): Multi-phase audit skill (recon, hunting, candidate validation, independent verification, reporting) that seeded Cloudflare's vulnerability discovery harness.
- [OpenCode Console key theft](https://x.com/sentient_agency/status/2112126626276532542): An attacker broke into a legacy system on October 16 and stole provider API keys users had saved on OpenCode's servers; some users found out from the bill. Don't store provider keys with a third party.
- [Nexus-CLI](https://github.com/xamrayev/nexus-cli): Go proxy that exposes DeepSeek V3/R1 to Claude Code and Ollama via a free web account instead of an API key; that depends on scraping the web login, so treat it as fragile and a terms-of-service risk.
