## Agent skills

- [Build once, run on any agent](https://github.blog/ai-and-ml/github-copilot/build-once-run-on-any-agent-a-practical-guide-to-agent-skills/): GitHub's guide to portable skill files that capture repeatable engineering work, while tools, project context, and permissions stay host-specific.
- [GoogleChrome/modern-web-guidance-src](https://github.com/GoogleChrome/modern-web-guidance-src): Chrome team's skills embedding web-platform best practices and browser compat data to steer coding agents off legacy patterns, and the source repo includes tooling to calibrate and evaluate them.
- [MengTo/Skills](https://github.com/MengTo/Skills): Curated skills for designers and builders using Codex, Claude, and Cursor to produce UIs, landing pages, games, and agent loops.
