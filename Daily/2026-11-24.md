## Claude Code releases

- [v2.1.321](https://github.com/anthropics/claude-code/releases/tag/v2.1.321) makes `claude-fable-5-2` the default Fable model (1M context, $8/$40 per Mtok, $0.20/Mtok cache reads) and adds `--settings <file>` to `claude remote-control`.
- [v2.1.329](https://github.com/anthropics/claude-code/releases/tag/v2.1.329) adds a trust-dialog warning showing where a folder's hooks are declared, plus a warning when managed-settings hooks fail to load. `/tasks` now lists scheduled tasks, `/loop` wakeups, the goal and forks.
- [v2.1.330](https://github.com/anthropics/claude-code/releases/tag/v2.1.330) adds sign-in to orgs managed in the Enterprise Admin Console, plus "easel", a built-in mod that draws charts on request.
- [v2.1.331](https://github.com/anthropics/claude-code/releases/tag/v2.1.331) adds Code Mode in terminal sessions on Bedrock, Google's Agent Platform, Foundry and Claude Platform on AWS, and `oidc.groups_jsonpath` for the Claude apps gateway.
- [Background subagents now cost less](https://x.com/bcherny/status/2118130958679605322): the 30-second status-line update used to re-read the whole conversation, and Haiku 5.5 now writes it from short notes at about 99% lower cost.
- [Side panel redesign on desktop](https://x.com/ClaudeDevs/status/2124978802006851961): Files, Changes and Terminal open as tabs beside the session and can be popped out. It's rolling out on Mac first.

## Claude Ship and agent review

- [Claude Ship launches in beta](https://x.com/bcherny/status/2124961485801836573) for Team and Enterprise, targeting the gap between agents writing code and PRs actually shipping.
- [Rollout guidance for /ship](https://x.com/bcherny/status/2124961488691740941): anyone can use `/ship`, admins enable it per GitHub repo, and Approvals should start in observe mode on one repo.
- [Claude Ship policy model](https://x.com/0xkvro/status/2125227631549317196): one agent reviews, one fixes, one approves only if the policy file allows. Docs can be auto-approved, while payments always need two humans, so the policy file is the real work.
- [review-pr](https://swipe.md/tools/review-pr) is a review contract for agents. It covers correctness, security, lifecycle, errors and tests, and it rules out speculative warnings, style nits and untouched code.

## Context and token efficiency

- [Anthropic MCP "code mode" paper](https://x.com/rincyXIII/status/2125237198286918012) claims an agent's tool context fell from 150k to 2k tokens. The agent writes code that calls tools exposed as `.ts` files, instead of calling tools directly, then filters results before answering.
- [mq](https://swipe.md/tools/mq) is "jq for Markdown". It extracts the smallest section containing the rules or evidence, so agents don't read whole documents.
- [Graft](https://swipe.md/tools/graft) builds a tree-sitter symbol and call graph of a repo as local files. It needs no model or API key and no hosted vector DB, and agents can query callers, references and ranked files.
- [GLM-5.4](https://simonwillison.net/2026/Nov/23/glm-54/) is Z.ai's first looped-transformer model, where a group of layers is re-run within one forward pass. It's a different route to more compute per token.

## Agent harnesses and standards

- [Harness breakdown](https://x.com/L1vsun/status/2125241469870977292) explains why two agents on the same model behave differently, using six harness layers (tools first). It frames the shift from prompt to context to harness engineering.
- [Agent Skills donated to the Agentic AI Foundation](https://x.com/ClaudeDevs/status/2113328526413996100), alongside MCP. Over 70 platforms have integrated the standard since December 2025, including ChatGPT, Cursor, Copilot and VS Code.
- [MCP Tasks and Elicitations in Claude](https://x.com/bcherny/status/2113781429436092466): Tasks let plugins run long jobs such as deep research and report back when done.
- [Karpathy at Sequoia AI Ascent](https://x.com/RRRangle/status/2125238084501467288): "Vibe coding raises the floor. Agentic engineering raises the ceiling." The talk covers a path from agents to specs, review and policy.

## Agent tooling and session management

- [AgentsView](https://swipe.md/tools/agentsview) imports session history from Codex, Claude Code, Cursor and 20+ other agents into local SQLite. It gives you search over messages and tool calls, plus cross-agent token and cost reports.
- [Swipe: Search the work your agents already did](https://swipe.md/issues/search-your-agent-history) covers local search over agent sessions, a codebase map and a private inbox for projects and agents.
- [Swipe: Agents that work while you sleep](https://swipe.md/issues/agents-that-work-while-you-sleep) covers keeping agents running with the lid closed, keeping API keys out of the chat, and handing work between parallel sessions.
- [Swipe: Claude in plain English](https://swipe.md/issues/claude-in-plain-english) covers a plugin that rewrites Claudish into plain English, a menu bar app that swaps accounts at the rate limit, local agent memory, and a skill that stops agents quitting early.
- [shot-scraper video](https://simonwillison.net/2026/Jun/30/shot-scraper-video/?utm_source=substack&utm_medium=email) (shot-scraper 1.10) records Playwright videos from a `storyboard.yml`, so agents can produce demo videos of their own work.

## Skills and repos

- [agentic-awesome-skills](https://github.com/sickn33/agentic-awesome-skills) is a catalog of 3,137+ `SKILL.md` playbooks for Claude Code, Codex, Cursor and Gemini CLI. AAS Core adds local search, agent-owned selection and plan preview.
