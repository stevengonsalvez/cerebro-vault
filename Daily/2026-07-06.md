# CEREBRO — 2026-07-06

## Coding agents

- Minimal-pair study claims code cleanliness doesn't affect agent task completion — but community pushback notes "clean" condition used AI-cleaned repos, not human-organized ones, undercutting conclusion ([arxiv](https://arxiv.org/abs/2605.20049)).
- [pxpipe](https://github.com/teamchong/pxpipe) cuts Claude Code input tokens by rendering bulky context (system prompt, tool docs, history) as images — dense text packs ~3.1 chars/image-token vs ~1 char/text-token, same vision channel reads it back.
- [codebase-memory-mcp](https://github.com/DeusData/codebase-memory-mcp) indexes repos into persistent knowledge graph via tree-sitter across 158 languages — Linux kernel (28M LOC) in 3min, sub-ms structural queries, 99% fewer tokens, single static binary.
- [130+ page survey on always-on agents](https://x.com/omarsar0/status/2073850909684293780) — systems whose future behavior depends on durable state (task ledgers, permissions, credentials, provenance, triggers) beyond simple memory.
- Claude Code ships [Artifacts](https://x.com/claudeai/status/2067671912038240487): interactive pages from a session (PR walkthroughs, dashboards) shareable via private link, beta on Team/Enterprise — [early user take](https://x.com/bcherny/status/2067700226669060207) says it's become daily-driver for code visualization and diagrams.
- Codex getting "Ultra" tier per [OpenAI eng tweet](https://x.com/thsottiaux/status/2073933490513752151) — no detail yet.
- [Bindu Reddy](https://x.com/bindureddy/status/2074005576691142857) argues no single model wins chat+code — future is prompt-routed mixture-of-agents by intent.
- [Meituan LongCat-2.0](https://x.com/Chinazhidx/status/2071807454153961739): 1.6T params (~48B active), 1M context, MOPD arch (agent/reasoning/interaction experts), claims SWE-bench Pro 59.5 > Gemini 3.1 Pro/GPT-5.5/Opus 4.6 — to be open-sourced.
- [Interconnects: frontier post-training recipe review](https://www.interconnects.ai/p/frontier-post-training-recipe-review) w/ Finbarr Timbers on getting an Olmo-style recipe to frontier quality.
- [Interconnects: Claude Fable 5 safety fables](https://www.interconnects.ai/p/claude-fable-5-and-new-ai-safety) — Anthropic quietly classified/steered "AI safety" research queries, later added a classifier akin to other safety domains after pushback.
- [System prompt leaks repo](https://github.com/asgeirtj/system_prompts_leaks) — extracted prompts from Claude/ChatGPT/Gemini/Grok/Cursor/Copilot etc, now diffing Opus 4.8 → Fable 5 changes.
