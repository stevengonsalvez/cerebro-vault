# CEREBRO — 2026-08-13

## Coding agents & CLI

- [Codex: 0 to 10M Users](https://www.latent.space/p/chatgpt-work): OpenAI's Akshay Nathan on Codex MAU up >10x since Jan, thesis being the ~100x of people who use code but can't write it is the real prize once agentic interfaces get good enough.
- [Claude Code v2.1.229](https://github.com/anthropics/claude-code/releases/tag/v2.1.229): adds `remote-control --continue` for resuming sessions, server-supplied hooks for self-hosted runners, and SSE keepalives to stop long-thinking streams idle-timing-out.
- [oh-my-pi](https://github.com/can1357/oh-my-pi): Rust-core (~80k LOC) terminal coding agent forked from Pi, 60+ providers, 31 tools, LSP+DAP integration, hash-anchored edits; PRs open to all as trial.
- [Agent Plugins 1.0](https://github.blog/changelog/2026-08-12-agent-plugins-1-0-in-vs-code-copilot-cli-and-the-copilot-app): cross-client plugin spec (AWS, Anysphere, Microsoft, OpenAI, Vercel) so one plugin runs in VS Code, Copilot CLI, and the Copilot app, chipping at the walled-garden agent ecosystem.
- [addyosmani/agent-skills](https://github.com/addyosmani/agent-skills): packaged senior-engineer workflows (define/plan/build/verify/review/ship) as reusable skills for coding agents to follow consistently.
- [GLM-5.2 is the step change for open agents](https://www.interconnects.ai/p/glm-52-is-the-step-change-for-open): Nathan Lambert flags GLM-5.2 crossing a capability threshold for open-weight agentic models, alongside new open RL recipes for terminal agents.
- [Your contributors are AI-first now](https://github.blog/open-source/maintainers/your-contributors-are-ai-first-now-is-your-project/): AutoGPT maintainer's playbook for repo instructions, gates, and boundaries to keep AI PR contributors in check.
- [openwiki](https://github.com/langchain-ai/openwiki): CLI that has an agent read your codebase and generate/maintain a linked Markdown wiki, built as memory for agents with a visualizer for humans.
- [Phind (Show HN)](https://www.phind.com): GPT-4-powered dev search; HN notes it already owns the niche, real problem is monetizing unlimited API calls.

## LLM mechanics

- [How to steal a Reasoning Trace](https://www.latent.space/p/ainews-how-to-steal-a-reasoning-trace): AINews on a paper showing reasoning-trace extraction is essentially speculative decoding in disguise, feeding the interpretability/alignment/CoT-monitoring debate.
- [I beat mem0 on long eval memory](https://octopodas.com/): builder claims to outperform mem0 on long-horizon agent memory evals, relevant if you're picking a memory layer for multi-agent systems.
- ["I gave Claude one MCP server..."](https://www.reddit.com/r/ClaudeAI/comments/1vmzn9w/i_gave_claude_one_mcp_server_and_it_chains_an_llm/): single MCP server used to chain an LLM, image, and video model in one Claude run, illustrating MCP as a composition layer not just a tool call.

## Vibe-coding & agent orchestration

- [Orca](https://github.com/stablyai/orca): desktop/mobile ADE that runs Codex, Claude Code, OpenCode, or Pi side-by-side in separate git worktrees with unified search, account switching, and usage tracking across a fleet of agents.
- [SnapState](https://snapstate.dev): persistent state layer for AI agent workflows, targets the "agent forgets everything between runs" problem.
- [book-to-skill](https://github.com/virgiliojr94/book-to-skill): converts a technical book/PDF into a Claude Code skill, claims 24-51x fewer tokens than dumping the book into context per query.
- [agency-agents](https://github.com/msitarzewski/agency-agents): native desktop app that browses a roster of specialized personality-driven agents and one-click installs them into Claude Code, Cursor, Codex, Gemini, etc.
- [Ballet](https://www.ballet.dev/): describes-the-outcome workflow automation that writes real API integrations; HN pushback is it's a commodity market and "just write Python + Claude" already beats it.
- [LaraCopilot](https://www.producthunt.com/products/laracopilot): agentic engineer that builds full apps, another entrant in the vibe-coding-as-product wave.

## Agentic SaaS & funding

- [Lovable raises $400M Series C](https://lovable.dev/blog/series-c): $13.3B valuation led by Menlo/Scaleup Europe; community skeptical post-Claude Code and flags Lovable's generated code as bloated with unnecessary layers.
- [OmniRoute](https://github.com/diegosouzapw/OmniRoute): free MIT AI gateway aggregating 290+ providers/500+ models with quota-aware fallback and prompt-compression claiming 15-95% token savings, works with Claude Code/Codex/Cursor/Copilot.
- [TencentDB Agent Memory](https://github.com/TencentCloud/TencentDB-Agent-Memory): team-level shared memory hub turning chats/docs/code into governed memory assets (Chat Memory, Skill, LLM-Wiki, Code-Graph) across agents/frameworks.
- [Cohesor](https://www.producthunt.com/products/cohesor): pitches itself as a neutral control plane for enterprise AI agents.
- [Argos](https://www.producthunt.com/products/argos): lets AI agents attach screenshots/videos directly to pull requests.
- [Grok Bot](https://www.producthunt.com/products/grok): xAI's "AI teammates you can give real work to" launch on Product Hunt.
