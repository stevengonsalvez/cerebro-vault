# CEREBRO — 2026-08-03

## Coding agents & CLI

- [Claude Code v2.1.215](https://github.com/anthropics/claude-code/releases/tag/v2.1.215): `/verify` and `/code-review` no longer auto-run on their own, invoke explicitly.
- [Claude Code v2.1.214](https://github.com/anthropics/claude-code/releases/tag/v2.1.214): fixes single-segment `dir/**` allow rules over-approving writes anywhere in the tree, closes a Windows PowerShell 5.1 permission-check bypass.
- [Claude Code v2.1.212](https://github.com/anthropics/claude-code/releases/tag/v2.1.212): `/fork` now spins the conversation into a background session with its own row in `claude agents`, old in-session subagent launch renamed `/subtask`.
- [Claude Code v2.1.211](https://github.com/anthropics/claude-code/releases/tag/v2.1.211): new `--forward-subagent-text` flag streams subagent text/thinking into stream-json output, permission previews now neutralize bidirectional-override/zero-width spoofing chars.
- [stablyai/orca](https://github.com/stablyai/orca): ADE runs Codex/Claude Code/OpenCode/Pi side by side, each in its own git worktree, one dashboard with cross-provider usage tracking.
- [esengine/DeepSeek-Reasonix](https://github.com/esengine/DeepSeek-Reasonix): DeepSeek-native terminal agent as a single static Go binary, tuned around DeepSeek's prefix cache to keep long-session token costs low.
- [alibaba/open-code-review](https://github.com/alibaba/open-code-review): Alibaba's internal review bot open-sourced, deterministic pipeline + LLM agent, line-level comments, built-in NPE/thread-safety/XSS/SQLi ruleset, OpenAI/Anthropic-compatible.
- [CLI that enforces agent governance with stop hooks + CI](https://www.reddit.com/r/ClaudeAI/comments/1ve4wyd/cli_that_enforces_agent_governance_with_stop/): locks agent behavior with stop-hook + CI gates instead of relying on AGENTS.md conventions alone.
- [Termexo](https://www.producthunt.com/products/termexo): local Windows workbench wrapping Claude Code and Codex.
- [Lumichats](https://www.producthunt.com/products/lumichats-offline): pitched as a Claude Code alternative for people who avoid the terminal.
