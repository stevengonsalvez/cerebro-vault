## Coding agents

- [v2.1.332](https://github.com/anthropics/claude-code/releases/tag/v2.1.332): Claude Code adds MCP-server-shipped skills (beta, shown as `server:skill`) and a `PreSkillShellCommand` hook that can block a skill's inline shell commands on load, which gives you a new control point for skill-borne shell execution.
- [Really excited about this one. MCP servers can now ship with their own skills...](https://x.com/bcherny/status/2125292098165612585): Boris Cherny's announcement of the same feature, so tools packaged with MCP no longer need hand-written usage instructions.
- [MCP turns two!...](https://x.com/ClaudeDevs/status/2125289794871963935): MCP is moving from tool/data plumbing toward agent-to-agent communication, with Skills over MCP and Tasks as the first steps.
- [v2.1.322](https://github.com/anthropics/claude-code/releases/tag/v2.1.322): Earlier Claude Code release, low signal next to 2.1.332.
- [How iFood scales coding agents across 15,000 repositories](https://openai.com/business/customer-stories/ifood): Remote-sandbox agent platform turns engineering tasks into API calls returning merge requests, at 25k+ runs, about $0.04 per run, and 2x+ vulnerabilities fixed.
- [mattpocock/skills: Skills for Real Engineers](https://github.com/mattpocock/skills): Small, composable, model-agnostic skills set pitched as an alternative to process-owning frameworks like GSD, BMAD and Spec-Kit.
- [emilkowalski/skills: Skills for Designers and Engineers](https://github.com/emilkowalski/skills): UI and animation judgement skills from a former Vercel and Linear engineer, aimed at faster design decisions.
- [AlphaMorph agents researching how AlphaMorph should evolve](https://x.com/alphamorpheus/status/2125212853384716356): Self-improving research loop with scout, architect, builder roles, and the architect locks success criteria cryptographically before results exist, which is a neat guard against moving goalposts.

- [Three LLM inflection points in twelve months](https://simonwillison.net/2026/Nov/24/llm-inflection-points/): Simon Willison's written version of his AI Engineer Code Summit keynote on the three step changes in LLM and coding-agent ability this year.

## Token, context and cost tricks

- [Why does Grok Bot burn the weekly limit so fast?](https://x.com/Mr_Buzzoni/status/2125183346258878508): Every message rereads the full chat and a 5-minute loop fires 8,640 times a month, so the fix is a harness plus loop and graph engineering over a shared Obsidian vault.

## Agent infrastructure and tooling

- [firecrawl/firecrawl](https://github.com/firecrawl/firecrawl): Self-hostable web-to-markdown API that also runs as a local MCP server, giving agents a clean web-data path.
- [Tracer-Cloud/opensre](https://github.com/Tracer-Cloud/opensre): Alpha CLI agent that reads a failed CI run, traces the cause and pushes a fix for review, self-hosted with your own models.
