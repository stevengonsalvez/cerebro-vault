## Agentic SaaS & Mobile

- [T3 Code mobile + multi-machine](https://x.com/theo/status/2071722505979736087) — T3 Connect lets one mobile app switch between repo clones on 4 machines; thread-per-machine routing is the key mechanism.

## Agent Memory & Knowledge

- [Agent-managed personal wiki](https://x.com/mattpocockuk/status/2071607607714890181) — Karpathy-style knowledge base ingesting X, Discord, Gmail every few hours; intended as the persistent environment for future agent loops.
- [Todoist MCP for task decomposition](https://x.com/mattpocockuk/status/2071674814213861757) — simple use case: agent breaks to-do items into subtasks via MCP before execution; low ceremony, high leverage.
