# CEREBRO — 2026-08-10

## Coding agents & CLI

- Claude Code [v2.1.219](https://github.com/anthropics/claude-code/releases/tag/v2.1.219) ships Opus 5 as default Opus model (1M context, fast mode $10/$50 per Mtok) plus `sandbox.network.strictAllowlist` for silent host-denial in sandboxed commands.
- Claude Code [v2.1.218](https://github.com/anthropics/claude-code/releases/tag/v2.1.218) moves `/code-review` to a background subagent so reviews stop filling your main conversation.
- [Auto mode becomes default](https://claude.com/blog/auto-mode-default-in-claude-code) for Pro/Max/Team plans from Aug 14, longer autonomous runs with better dangerous-command detection than manual review.
- [oh-my-pi](https://github.com/can1357/oh-my-pi) is a Rust-core (~80k lines) terminal coding agent fork of Pi: hash-anchored edits, LSP/DAP, 60+ providers, 31 built-in tools, subagents.
- [Simon Willison quotes the Opus 5 system prompt](https://simonwillison.net/2026/Aug/9/claude-opus-5-system-prompt/#atom-everything), including the Fable/Mythos export-control suspension and restoration timeline baked into model context.

## Model releases & analysis

- [Opus 5 lands at "Fable-level performance, half the price"](https://www.latent.space/p/ainews-claude-opus-5-fable-level) per Latent Space, benchmarks edge Fable though Anthropic's own messaging is more conservative.
- [Interconnects on GLM-5.2](https://www.interconnects.ai/p/glm-52-is-the-step-change-for-open) calls it a capability step-change for open agentic models, worth watching as the open-weight alternative to closed coding agents.
- [Reddit thread](https://www.reddit.com/r/ClaudeAI/comments/1vka93j/apparently_opus_5_is_better_a_photogrammetry/) claims Opus 5 shows unexpected strength at photogrammetry tasks, anecdotal but signals broader spatial-reasoning gains.
- [Interconnects, May roundup](https://www.interconnects.ai/p/some-ideas-for-what-comes-next-may) covers Gemini Flash 3.5, Mythos, and the open/closed balance shifting as economics of AI get real.
- [Claude Fable 5 and new AI safety fables](https://www.interconnects.ai/p/claude-fable-5-and-new-ai-safety) digs into Anthropic's export-control-driven safety classifier changes around the Fable/Mythos release.
- [AirLLM](https://github.com/lyogavin/airllm) runs 70B models on a 4GB GPU without quantization, even Kimi K3 (2.8T MoE) under 4GB, relevant for local inference cost tricks.

## Agent skills & code intelligence

- [code-graph-rag](https://github.com/vitali87/code-graph-rag) builds a Tree-sitter + Memgraph knowledge graph over a multi-language monorepo for natural-language query/edit.

- [harveyai/harvey-labs](https://github.com/harveyai/harvey-labs) is an open benchmark (LAB) for evaluating LLM agents on real legal work with rubric-based scoring.

## Agentic SaaS & orchestration

- [stablyai/orca](https://github.com/stablyai/orca) is a desktop/mobile ADE running Codex, Claude Code, OpenCode, or Pi side-by-side in isolated worktrees with usage tracking.
- [Cloudflare OS](https://github.com/cloudflare/cloudflare-os) is Cloudflare's internal Workers-based agent workspace for docs/apps/agents, now open-sourced.
- [OmniRoute](https://github.com/diegosouzapw/OmniRoute) aggregates 43 provider free tiers (516 models) into one gateway with quota-aware fallback and prompt compression claiming 15-95% token savings.
- [TencentDB Agent Memory](https://github.com/TencentCloud/TencentDB-Agent-Memory) is a team-level shared memory hub (Chat Memory, Skill, Wiki, Code-Graph) for cross-agent/cross-framework reuse.
- [Toolport](https://www.producthunt.com/products/conduit-12) is a one-MCP-setup gateway aggregating tools for multiple agents.
- [SnapState](https://snapstate.dev) offers persistent state for AI agent workflows.
- [Omniwork](https://www.producthunt.com/products/omniwork-2) bills itself a "Creative Agent OS" for desktop creative AI agents.
- [archify](https://github.com/tt-a1i/archify) is an agent skill generating self-contained, animated HTML architecture/sequence/data-flow diagrams from a codebase description.

## Vibe-coding & repos

- [OpenChamber](https://openchamber.dev/) is an ADE that keeps agents working toward a set session goal across turns, runs one task across up to five models (multi-run/fusion), and groups large diffs into a walkthrough of ordered steps.
