# CEREBRO — 2026-07-01

## Coding agents

Anthropic shipped [Claude Sonnet 5](https://www.anthropic.com/news/claude-sonnet-5), its most agentic Sonnet yet, now the [default in Claude Code with a 1M-token context window and $2/$10-per-Mtok promo pricing through Aug 31](https://github.com/anthropics/claude-code/releases/tag/v2.1.197). Early takes call it [close to Opus 4.8 at a fraction of the cost](https://x.com/AlexFinn/status/2072018806919381411), but Anthropic's own post concedes [Opus 4.8 is still cheaper and better on agentic/search/computer-use benchmarks](https://www.anthropic.com/news/claude-sonnet-5), muddying the pitch. The efficiency story is contested: one thread says Sonnet 5 [beats Opus by generating ~2x the tokens per task](https://x.com/theo/status/2072067204259143837), a follow-up reframes that as [OpenAI-style token efficiency being the real win Sonnet 5 lacks](https://x.com/theo/status/2072091191219454191), and [AINews attributes the gap to tokenizer changes plus 3-6x more turn-taking](https://www.latent.space/p/ainews-sonnet-5-today-and-fable-5) — [Simon Willison's rundown of the official docs](https://simonwillison.net/2026/Jun/30/claude-sonnet-5/#atom-everything) is the more actionable source than the launch post itself. Sonnet 5 also went GA in [GitHub Copilot](https://github.blog/changelog/2026-06-30-claude-sonnet-5-is-generally-available-for-github-copilot). Copilot Agent separately landed in [JetBrains AI Assistant](https://github.blog/changelog/2026-06-30-copilot-agent-is-now-available-in-jetbrains-ai-assistant). [Cursor shipped an iOS app](https://www.producthunt.com/products/cursor) for driving coding agents from a phone.

Fable/Mythos 5 access whiplash: [export-control lift announced](https://x.com/theo/status/2072106799625646177), then [ban lifted](https://x.com/theo/status/2072105744485523484), then [usage-credit clawback announced for after July 7](https://x.com/theo/status/2072173365318840573), netting one user [3 days full usage instead of the promised 15](https://x.com/theo/status/2072173639148126641). [Claude Desktop is now on Linux (Ubuntu/Debian, beta)](https://x.com/bcherny/status/2072000214634742243), giving Claude Code/Cowork/chat parity with browser and terminal.

## LLM mechanics

Anthropic is formally naming "context engineering" — curating what the model sees — as [the successor to prompt engineering, with bloated context framed as the silent killer of agent reliability](https://x.com/shmidtqq/status/2071989087225954437). Adjacent buzzphrase "loop engineering," credited to Claude Code's Boris Cherny and OpenClaw's Peter Steinberger, is catching on as the term for [the iterate-at-length loops that let agents build software end-to-end](https://x.com/AndrewYNg/status/2071988145667928442). Lilian Weng's [deep dive on scaling laws](https://lilianweng.github.io/posts/2026-06-24-scaling-laws/) reaffirms the loss-vs-compute power law as a reproducible predictor, not a one-off fit.

## Vibe-coding & repos

[obra/superpowers](https://github.com/obra/superpowers) packages a full agentic-skills methodology — composable skills plus bootstrapping instructions — for coding agents, and is now hiring a community/code maintainer. One power-user reports [running Claude Code entirely from a wiki as a cross-repo master controller with Todoist as task tracker](https://x.com/mattpocockuk/status/2071901405690949874), an unusual but instructive orchestration pattern.

## Agentic SaaS / infra

[google/agents-cli](https://github.com/google/agents-cli) turns any coding assistant into a builder/deployer for agents on Google Cloud's Agent Platform, adding skills and commands for build/scale/govern/optimize workflows. [diegosouzapw/OmniRoute](https://github.com/diegosouzapw/OmniRoute) is a free AI gateway aggregating 231+ providers behind one endpoint (Claude Code, Codex, Cursor, Cline, Copilot) with claimed 15-95% token savings via compression and auto-fallback — treat the "~1.6B free tokens/month" claim skeptically, it's vendor-reported.
