# CEREBRO — 2026-07-20

## Coding agents & CLI orchestration

- Claude Code next version: subagents run background by default, keep chatting while they work, foreground opt-in via explicit ask ([tweet](https://x.com/bcherny/status/2071647677591466098)).
- [Orca](https://github.com/stablyai/orca) — ADE running Codex/ClaudeCode/OpenCode/Pi side-by-side, each own worktree, one dashboard, usage/rate-limit tracking across providers.
- [herdr](https://github.com/ogulcancelik/herdr) — terminal agent multiplexer, detach/reattach over ssh, sessions survive restarts, socket API lets agents spawn/control panes themselves.
- [jcode](https://github.com/1jehuang/jcode) — new coding agent harness targeting multi-session workflows and performance ceiling.
- [pi](https://github.com/earendil-works/pi) — self-extensible agent harness: unified LLM API, agent loop, TUI, CLI, modular npm packages.
- [MagicPath 2.0](https://x.com/skirano/status/2054975534539370708) — multiplayer canvas where humans + Codex/Claude Code build prototypes together, live agent view.
- [mattpocock/skills](https://github.com/mattpocock/skills) — small composable Claude/agent skills library, model-agnostic, alternative to heavier frameworks (GSD/BMAD/Spec-Kit).
- Vercel's Andrew Qu on agents as new software category: `eve` framework, skills/sandboxes/agent-readable sites as the emerging stack ([latent.space](https://www.latent.space/p/vercel-agents-new-software)).
- Autoresearch: self-improving agent "recipes" and outer feedback loops, humans still central ([latent.space](https://www.latent.space/p/autoresearch-introspection)).

## Agent security & infra

- [agent-security](https://x.com/nykdotdev/status/2079068942681993237) — open-sourced preflight gate for coding agents: catches poisoned repos, hostile content leaking into commits, destructive git commands before trust boundary crossed.
- [cua](https://github.com/trycua/cua) — open computer-use drivers for cross-OS agent fleets, drives native apps in background without stealing cursor/focus, plus benchmarks (Cua Bench).
- [SnapState](https://snapstate.dev) — persistent state layer for agent workflows (HN).
- Axon self-documents its API for agent-to-agent hiring/payment, no human in loop for integration ([tweet](https://x.com/axon402/status/2073787949490024568)).

## Token/context economics

- Deep research pipeline burned a whole Claude Max 5x limit in 30 min; lesson: dynamic prompts kill caching, static retrieval beats micro-optimization ([quesma.com](https://quesma.com/blog/custom-deep-research-pipeline/)).
- Reddit skill routes "thinking" to Claude, grunt coding to cheaper/free models as executor, judge/executor split for cost control ([reddit](https://www.reddit.com/r/ClaudeAI/comments/1v16bag/a_skill_that_saves_claude_usage_for_thinking/)).

- [LoRA Speedrun](https://github.com/Saivineeth147/lora-speedrun) — public wall-clock leaderboard for fine-tuning Qwen2.5-1.5B to GSM8K threshold, independently re-run 3x on fixed hardware, modded-nanogpt for fine-tuning.
