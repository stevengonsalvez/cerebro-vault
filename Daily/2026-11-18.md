## Coding agents: releases & harnesses

- [v2.1.327](https://github.com/anthropics/claude-code/releases/tag/v2.1.327): Claude Code adds `claude mcp add-json <name> -` to read server JSON from stdin, keeping tokens off the command line, plus a confirmation before `/install-github-app` changes a repo.
- [v2.1.317](https://github.com/anthropics/claude-code/releases/tag/v2.1.317): Claude Code now warns when `/schedule` attaches connectors you did not ask for, asks before sending your account email over the network from web/shell tools, and gains `onFailure: "block"` for Agent SDK hook callbacks.
- [0.170.0](https://github.com/openai/codex/releases/tag/rust-v0.170.0): Codex adds WebRTC negotiation for realtime voice in the TUI and auto-refreshed auth headers for OpenTelemetry HTTP exporters.
- [What is the best harness for each model?](https://runta.com/blog/introducing-frontierharness-eval-v1-1/): FrontierHarness v1.1 covers 27,280 runs and 83B tokens to test whether switching model should mean switching harness. HN pushback: the "64% of spend on failed runs" headline is editorialized, since "failed" only means missing pass criteria.
- [obra/superpowers](https://github.com/obra/superpowers): Composable-skills methodology that makes the agent ask what you are building before it writes code. Worth a look for skill structure.
- [affaan-m/ECC](https://github.com/affaan-m/ECC): Harness optimization bundle (skills, instincts, memory, security) spanning Claude Code, Codex, Opencode, and Cursor. Its README warns to install only from official channels.
- [cursor/plugins](https://github.com/cursor/plugins): Cursor's official plugin spec and first-party plugins, each with a `.cursor-plugin/plugin.json` manifest. The plugin format is converging across agents.
- [Matt Pocock on constraining agents](https://x.com/mattpocockuk/status/2122659341685694586): Experiment called `/constrain`: if too much choice hurts agents, allow React but force all state through Zustand/useReducer, enforced by harsh lint rules.

## Agent infrastructure & safety

- [External sandboxes for coding agents](https://simonwillison.net/2026/Nov/17/external-sandboxes-for-coding-agents/): Simon Willison explores running agent code in external sandboxes so a mistake or prompt injection from a local model cannot damage the host.
- [Building the Agent Host Protocol](https://github.blog/engineering/engineering-principles/building-the-agent-host-protocol-for-sessions-that-continue-across-devices/): GitHub's open protocol for agent sessions that persist across editors, apps, phones, and cloud. Session portability is becoming a protocol layer.

## GitHub Copilot updates

- [GPT-6.2 Astra and GPT-6.2 Sol](https://github.blog/changelog/2026-11-17-openais-gpt-6-2-astra-and-gpt-6-2-sol-now-available): Both models are now GA in Copilot, aimed at agentic coding and code review.
- [MAI Code 2 and MAI Code 2 Flash](https://github.blog/changelog/2026-11-17-mai-code-2-and-mai-code-2-flash-in-github-copilot): Microsoft's next-generation coding models land in Copilot.
- [Copilot Fusion updates](https://github.blog/changelog/2026-11-17-github-copilot-fusion-updates-more-availability-benchmarks-and-models): Fusion gets new models, more Copilot surfaces, and results on two public Terminal-Bench leaderboards.
- [Copilot Evals public preview](https://github.blog/changelog/2026-11-17-github-copilot-evals-is-now-in-public-preview): Lets you measure whether Copilot is still performing well as your prompts, models, skills, and tools change.
- [Copilot in JetBrains, Ignite releases](https://github.blog/changelog/2026-11-17-github-copilot-in-jetbrains-ignite-releases): Adds remote access, on-device voice dictation, browser-use controls, context usage shortcuts, and historical diffs.

## Review & CI bottlenecks

- [Harvard: AI coding agents shifted the bottleneck to code review](https://complexdiscovery.com/harvard-researchers-find-ai-coding-agents-shifted-the-bottleneck-to-code-review/): A working paper across 718 firms found about 30% more code, no measurable rise in finished work, and 49% longer review. It is not peer reviewed. HN pushback: the real bottleneck is up-front specification.
- [Launch HN: StarSling](https://starsling.dev): Agent-driven CI optimization that claims p95 test time dropping from 29m56s to 5m06s. HN comment: the metric that matters is deployable merges to main.
- [Glass Page](https://www.producthunt.com/products/glass-page): A place for humans to review an agent's work.
