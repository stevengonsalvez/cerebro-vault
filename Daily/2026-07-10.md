## Agentic SaaS

Anthropic launched Claude Tag — tag Claude into a Slack channel, it spins up sandboxed Claude Code instance per thread (own memory/permissions), clones+writes+tests+compiles, sandbox torn down after. Beta today for Enterprise/Team ([announcement](https://x.com/claudeai/status/2069468693017268244), [mechanics](https://x.com/bcherny/status/2069474689819480394), [proactive behavior](https://x.com/bcherny/status/2069474684610195914), [availability](https://x.com/bcherny/status/2069474691010707486)). Anthropic's own product team already gets 65% of new code from their internal version — signal this isn't just a demo ([internal usage](https://x.com/bcherny/status/2069474683372839253)).

`stablyai/orca` — ADE for running fleets of parallel coding agents (Codex/Claude Code/OpenCode/Pi) each in own worktree, one tracked view, usage/rate-limit tracking ([repo](https://github.com/stablyai/orca)).

MagicPath 2.0 — multiplayer canvas where humans + Codex/Claude Code build UI together in real time from codebase/data ([announcement](https://x.com/skirano/status/2054975534539370708)).

Open-source video editor fully driveable by Claude via MCP — editing, motion graphics, audio mixing ([reddit](https://www.reddit.com/r/ClaudeAI/comments/1useplq/i_built_a_free_opensource_video_editor_that/)).

Aura — OSS IDE for controlling coding agents with built-in loops ([producthunt](https://www.producthunt.com/products/aura-28)).
