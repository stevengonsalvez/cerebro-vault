## Coding agents

- [Pax by Pydantic](https://www.producthunt.com/products/pydantic): coding agent where even coding is a plugin, so the core is a bare agent loop and capability is composed in, worth watching as an alternative harness architecture from the Pydantic team.
- [NEXUS](https://www.producthunt.com/products/nexus-42): maps the codebase locally and restricts AI edits to changes you approved, a scope-gating approach to taming agent drift.
- [Ottante](https://www.producthunt.com/products/ottante): Mac app that checks the work your agents did, in the same verification-over-trust space as the review debate below.
- [@poteto on adversarial reviews](https://x.com/poteto/status/2117437607940681849): argues adversarial review burns tokens on nitpicks and YAGNI, and that the budget is better spent on empirical plus formal verification, so pstack is dropping its interrogate skill.

## Agent tooling and fleets

- [mvanhorn's 16-tool agent browser benchmark](https://x.com/theo/status/2126062066809307637): tested 16 browser and computer-use tools on one Apple Silicon Mac, and two little-known winners (ardiabrowser at 3k stars, opencode browse at 1.1k) beat agent-browser (54k) and Stagehand (26k) on speed and RAM, so star counts are a poor guide.
- [WhipDesk](https://www.producthunt.com/products/whipdesk): controls AI coding agents from your phone, for approving and steering long-running sessions away from the desk.
- [DeskFleet](https://www.producthunt.com/products/deskfleet): runs coding agents together across a team's machines, a multi-host fleet-orchestration pitch.

## Agentic SaaS

- [Flurra](https://www.producthunt.com/products/flurra): lets Claude or ChatGPT edit your videos, one more example of chat agents driving a full creative tool.
