# CEREBRO — 2026-07-11

## Coding agents

- Claude Code [v2.1.207](https://github.com/anthropics/claude-code/releases/tag/v2.1.207) drops Auto mode's opt-in gate on Bedrock/Vertex/Foundry and fixes terminal freeze on long streamed output, useful if you're on managed cloud deploys.
- [Claude Code desktop ships in-app browser](https://x.com/bcherny/status/2075742647075877249), sandboxed, lets agent read/click/interact with docs or dev servers directly, no more copy-paste context.
- [theo](https://x.com/theo/status/2075742083370127504): Codex's "ultra" effort setting cascades to all subagents (token burn), no per-agent override; Claude Code lets you pin subagent effort independently.
- [theo again](https://x.com/theo/status/2075765314483376285): Claude Code's subagent orchestration beats Codex's, programmatic orchestration still the only sane pattern for multi-agent coding.
- [theo](https://x.com/theo/status/2075776733626892542) and [skirano](https://x.com/skirano/status/2075672649741861005) on model routing: gpt-5.6-sol performs better inside Claude Code than Codex; skirano's stack = Sol Ultra for planning, Sol Medium for coding, Terra High for context/search subagents, Luna for trivial file ops.
- [rasbt](https://x.com/rasbt/status/2075573860796436626): for agentic coding, prefer a cheaper model at higher effort over a pricier model at lower effort, same/better perf for less cost.
- [Someone built a phone-resumable Claude Code session](https://www.reddit.com/r/ClaudeAI/comments/1ut74vr/i_built_a_browser_control_panel_for_claude_code/) via browser control panel, close laptop, pick up thread on mobile.

## Agentic SaaS

- Anthropic launched [Claude Tag](https://x.com/claudeai/status/2069468693017268244) for Slack: tag Claude in a channel, it gets its own sandbox, clones repos, writes/tests/compiles code, sandbox destroyed after ([details](https://x.com/bcherny/status/2069474689819480394), proactive behavior [here](https://x.com/bcherny/status/2069474684610195914)); beta live today for Enterprise/Team ([more](https://x.com/bcherny/status/2069474691010707486)). 65% of Anthropic's internal product-team code now comes from this internal tool ([bcherny](https://x.com/bcherny/status/2069474683372839253)).
- [MagicPath 2.0](https://x.com/skirano/status/2054975534539370708): multiplayer canvas where humans + coding agents (Codex, Claude Code) design/build together in real time against your codebase.

## Coding agent tooling / MCP / skills

- [codebase-memory-mcp](https://github.com/DeusData/codebase-memory-mcp): tree-sitter-based code intelligence MCP server, indexes repos (Linux kernel in 3min), sub-ms structural queries, 99% fewer tokens, single static binary, no deps, big win for agent context efficiency.
- [mattpocock/skills](https://github.com/mattpocock/skills): lightweight, composable Claude skills for real engineering (not vibe coding), model-agnostic, contrasts with heavier frameworks like GSD/BMAD/Spec-Kit.
- [addyosmani/agent-skills](https://github.com/addyosmani/agent-skills): production-grade skill set covering DEFINE→PLAN→BUILD→VERIFY→REVIEW→SHIP pipeline for coding agents.
- [google-labs-code/stitch-skills](https://github.com/google-labs-code/stitch-skills): Agent Skills standard library for Google Stitch, works across Antigravity, Gemini CLI, Claude Code, Cursor.
- [mattpocockuk](https://x.com/mattpocockuk/status/2075495703028142364) floats shipping his own skills-installer CLI (`npx @ai-hero/skills init`) for per-agent customization and dependency tracking between skills.
- [SnapState](https://snapstate.dev): persistent state layer for AI agent workflows.
- [system_prompts_leaks](https://github.com/asgeirtj/system_prompts_leaks): regularly-updated dump of leaked system prompts across Claude, GPT-5.6, Gemini, Grok, Cursor, Copilot, useful for prompt-engineering reverse-engineering.

## CLI/TUI

- [claude-code-templates](https://github.com/davila7/claude-code-templates): ready-made agents/commands/hooks/MCP configs for Claude Code, plus new web dashboard (aitmpl.com) for browsing/installing.
