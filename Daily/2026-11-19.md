## CLI/TUI

- [Wait for pull request events with GitHub CLI](https://github.blog/changelog/2026-11-18-wait-for-pull-request-events-with-github-cli): `gh` v2.105.0 supports GitHub Event Streams, so you and your agents can block on a PR change with one command instead of polling.
- [CLI-Anything](https://github.com/HKUDS/CLI-Anything): generates agent-native CLIs for existing software and ships a community CLI-Hub (`pip install cli-anything-hub`).
- [FailTrace](https://github.com/Ri4dH/failtrace): takes a failed GitHub Actions run URL, locates the failing job and step, and reports what it takes to reproduce locally. Commenters note `nektos/act` already does local runs and question how faithfully any tool can match hosted runners.
- [astral-sh/uv](https://github.com/astral-sh/uv): the Rust Python package and project manager (10-100x faster than pip) with a universal lockfile and inline script dependencies, still the default for agent-run Python.
