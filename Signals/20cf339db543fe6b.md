# v2.1.229

> Claude Code feature release: remote-control continuation and hook support.

<h2>What's changed</h2>
<ul>
<li>Documented <code>claude remote-control --continue</code> for resuming the most recent Remote Control session</li>
<li>Added server-supplied Claude Code hook support for self-hosted runner sessions, matching managed-environment behavior</li>
<li>Added SSE keepalive pings to gateway streaming responses during long thinking pauses, preventing idle-timeout disconnects on Vertex and Bedrock upstreams</li>
<li>Added plugin marketplace <code>command</code> sources: a local command (e.g. an IDE) prints the plugin directory, which is re-resolved each session and applied
