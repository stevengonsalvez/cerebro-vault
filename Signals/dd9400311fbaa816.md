# t3dotgg/tstack: The agent skills I use every day. Works with Claude Code and Codex.

> Agent skills collection for Claude Code and Codex; daily-use.

The agent skills I use every day, cleaned up so anyone can use them. They work in Claude Code and Codex. Some use T3 Code features when they are available and fall back to native tools when they are not.
| Skill | Say | What it does | 
|---|---|---|
| full-send | "full send" | Takes a change to a merged PR with nobody watching: proves it, reviews it, files it, babysits it, merges it. | 
| full-stop | "full stop" | Same as full-send , but stops when the PR is ready for you to merge. | 
| council | "council" | Gets review from three models from different providers, and loops until they agree. |
