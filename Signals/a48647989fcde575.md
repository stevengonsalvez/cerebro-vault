# majd/ipatool: Command-line tool that allows searching and downloading app packages (known as ipa files) for iOS, iPadOS, tvOS, and visionOS from the App Store.

> CLI tool for App Store management, solid CLI utility

ipatool is a command line tool that allows you to search for iOS, iPadOS, tvOS, and visionOS apps on the App Store and download a copy of the app package, known as an ipa file.
- Supported operating system (Windows, Linux or macOS).
- Apple ID set up to use the App Store.
You can grab the latest version of ipatool from GitHub releases.
You can install ipatool using Homebrew.
$ brew install ipatoolTo authenticate with the App Store, use the auth command.
Authenticate with the App Store
Usage:
  ipatool auth [command]
Available Commands:
  info        Show current account info
  login       Logi
