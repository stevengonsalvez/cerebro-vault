# Show HN: OmniDiff – Opensource, super fast, content aware Git difftool, in Rust

> Rust git difftool; CLI utility for terminal workflow

Fast, robust, accurate content-aware diffing.
- Robust: can diff 99.95% of code changes
- Content-aware: 98.8% of changes diffed using content-specific algorithms
| Content | Fast: under 100ms | Accurate: perfect | Accurate: near-perfect | 
|---|---|---|---|
| Code | 98% | 70% | 92% | 
| Pictures | 96% | 69% | 91% | 
| Cursors | 100% | 85% | 100% | 
| Fonts | 95% | 82% | 100% | 
| Archives | 88% | 87% | 87% | 
| Message catalogs | 100% | 83% | 83% | 
| PDFs | 57% | 100% | 100% | 
Speed measured on a T14s, Intel Core i7-1370P with 32 GB RAM (see Fast). PDFs have fewer than ten judged test cases
