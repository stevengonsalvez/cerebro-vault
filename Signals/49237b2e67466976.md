# Swipe: Remarc

> Attaches screen context to agent tasks; agent UI pairing.

Give the agent the part you can see
Remarc runs in the Mac menu bar. Select text, capture a screen area, or use its Chrome extension to attach a web element to a comment. A connected coding agent can read the comment and its context through MCP, then mark the work as in progress or resolved.
The useful first job is one visual snag that is painful to describe. Capture the exact area, say what looks wrong, and check the changed screen after the agent resolves it. This avoids a long prompt made from filenames and rough screen coordinates.
Comments stay local until you send them
Remarc needs macOS
