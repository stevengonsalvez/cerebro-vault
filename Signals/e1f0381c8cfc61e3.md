# Show HN: Unref – A Python dead code finder built on Ruff's parser

> Python dead-code CLI, terminal dev utility

An extremely fast Python dead code finder, written in Rust.
  Checking the whole CPython codebase (v3.15.0, about 2,300 files),
  measured with scripts/benchmark.py.
- Fast: 20x faster than vulture, it checks all of CPython in under a second.
- Just works: built-in rules for pytest, Pydantic, SQLAlchemy and more, so most projects need little or no configuration.
- Accurate: names are matched by module, so a used parse in one module does not hide an unusedparse in another.
- Ruff-style: same conventions, options and output style as Ruff, and it finds the unused code Ruff leaves out.
