# v2.1.295

> Claude Code release adding blocking hook failure modes

<h2>What's changed</h2>
<ul>
<li>Added <code>onFailure: "block"</code> for command and HTTP hooks: a hook that can't start, times out, or exits with an unexpected code blocks the action instead of letting it through</li>
<li>Added Program Status Protocol (OSC 7501) support: terminals that implement it can show whether Claude Code is working, waiting on you, or done</li>
<li>Added quoted text to the <code>/copy</code> picker, so a drafted message copies without its <code>&gt;</code> markers</li>
<li>Added a warning to <code>claude plugin install</code>, <code>enable</code>, <code>disable</code>
