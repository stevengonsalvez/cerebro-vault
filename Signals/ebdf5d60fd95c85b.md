# https://hiroute.ai

> Local model router cutting Claude Code and Codex token cost

🔥速码！难活贵模型干，简单活便宜模型干，还让 Codex/Claude/DSH 额度多用 3 倍！实测混合路由下，同等质量任务成本可降 90% 左右！
 HiRoute 是一款本地运行的智能模型路由器，专为 Codex、Claude Code 等 AI 编程助手设计。

它会实时分析每条新消息的复杂度，自动把简单任务丢给便宜模型，复杂任务才交给主力模型，从而大幅节省成本、优化资源分配。

核心亮点
🔹智能分流：按难度选模型，简单任务省钱，复杂任务保质量
🔹灵活配置：支持自定义任务类型路由 + 候选模型顺序
🔹安全可控：故障时明确提示，不“偷偷”降级；所有会话记录可查
🔹多平台支持：macOS 桌面应用 + Linux 命令行/服务
🔹开源免费：Apache-2.0 协议，可自托管、可审计
