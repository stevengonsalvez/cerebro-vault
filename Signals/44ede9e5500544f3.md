我们可能从一开始，就把 Agent Memory 想得太复杂了

最近一篇论文《Is Complex Agentic Memory Always Needed?》做了一个很有意思的实验：

不做 Memory Extraction，不做复杂的知识图谱，也不让 LLM 在写入时反复总结、更新记忆

只保留原始对话历史，在需要的时候检索出来，交给 LLM 自己推理

结果呢？

在 LoCoMo、LongMemEval 等四个 benchmark 的 7 组测试设置中，这套简单的 RAW-RAG 方案拿下了 6 组第一，最多领先对比的最强 Agentic Memory 系统 5.53 分

这恰好也是我们开发 Obelisk 时一直坚持的思路

我们认为，Agent 不应该只能看到别人替它总结好的「记忆」

因为一次代码修改背后的原因、一次失败的尝试、几个决策之间的依赖关系，都可能在总结和信息提取的过程中丢失

与其猜测未来什么信息值得记住，不如保留完整历史，让 Agent 在真正需要的时候自己去找

所以我们做了 Obelisk：

一个开源的 Coding Agent Session 检索系统

它可以直接查询 Claude Code、Codex、Hermes、Pi、Opencode 等 Agent 的历史 Session，包括对话、工具调用、Subagent 和工作流。
