One thing about working with coding agents: getting a feature built can be fast, but checking it properly is still work

You have to run the app, click through the new flow, make sure an old one didn’t break and then explain the bug back to the agent

@coderabbitai Verify now handles that first testing pass. It creates scenarios from PR changes, tests the running app, and keeps the recordings, screenshots and logs when something fails

The part I find most useful is being able to hand all that context back to a coding agent for the fix
