# b-nnett/codex-plusplus: Codex++ tweak system for the Codex desktop app

> Tweak system for Codex desktop app; agent tooling

A fresh macOS base for Codex++, kept outside the ChatGPT desktop app. The helper owns patching, connection status, recovery controls, and links to the project. The signed main-process patch hosts renderer Extensions through Electron's in-process webContents API; it opens no DevTools or extension-control network listener.
Codex++ 2.0 replaces the 1.x tweak system (still on the legacy-1.x branch) with a signed menu-bar helper. 1.x tweaks do not load in 2.0. Before installing 2.0, quit ChatGPT and remove 1.x, which restores the app when it can:
codexplusplus uninstall
Add --purge to also delete 1
