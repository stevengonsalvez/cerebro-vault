# FailTrace – Reproduce a failed GitHub Actions run locally from its URL

> Local CLI reproduces failed GH Actions runs; streamlines terminal workflow

Stop guessing why CI failed. Reproduce it locally.
Paste a failed GitHub Actions run URL. FailTrace finds the job and step that failed, matches them to the workflow file at that exact commit, pulls the failure out of the logs, and tells you what stands between you and reproducing it on your machine.
failtrace inspect https://github.com/owner/repo/actions/runs/123456789   # why did it fail?
failtrace plan    https://github.com/owner/repo/actions/runs/123456789   # how would it be reproduced?
failtrace repro   https://github.com/owner/repo/actions/runs/123456789   # reproduce it in Docker
