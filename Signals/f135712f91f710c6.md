# Show HN: Tmux-restore saves tmux windows and agent sessions across reboots

> tmux save/restore incl. agent sessions; terminal workflow tool

Reboot-proof tmux. Your coding agents pick up mid-conversation.
What it does · Install · How it works · Agents · Caveats · Contributing
Ever rebooted and lost a dozen tmux windows, along with the agent conversations running in them? tmux-restore saves everything every minute and right before shutdown, and puts it back when tmux starts. Panes running Claude Code, Codex, Gemini CLI, opencode or pi reopen the exact conversation they were in.
- Everything comes back. Sessions, windows, splits, working directories and scrollback.
