# lightpanda-io/browser: Lightpanda: the headless browser designed for AI and automation

> Headless browser built for AI agents; relevant agent infra

The headless browser built from scratch for AI agents and automation.
Not a Chromium fork. Not a WebKit patch. A new browser, written in Zig.
16x lighter and 9x faster than Chromium.
Requesting 933 real web pages over the network on a AWS EC2 m5.large instance. See benchmark details.
