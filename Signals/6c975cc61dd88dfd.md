# Show HN: Oak – Git alternative designed for agents

> Git tool explicitly designed for agents; novel tooling.

Oak
This repository is the open-source heart of Oak:
version control at the speed of agents. It's developed as a Cargo
workspace: a reusable VCS library plus the oak command-line client that
agents drive.
Bring your own agent (Claude Code, Codex, Cursor, …); Oak is the foundation it reads, writes, branches, and collaborates through. The substrate is shaped around how agents actually work — branch-per-session as the unit of work, branch descriptions in place of per-commit messages, and content-addressed lazy mounts that get an agent editing any repo in seconds.
