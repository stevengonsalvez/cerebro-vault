Orca 是一个开源的 Agent IDE。它直接接你自己的 Claude Code / Codex 等订阅，调度一整队 AI 编程 agent。今年 3 月开源的，GitHub 已经 13.6 万 star。

简单总结一下它都有什么功能：
编排：大任务丢给一个主 agent，然后主agent自己拆分，开几个 worker 在各自的 worktree 并行工作，最后把结果汇总回来

Chat / 终端随时切：同一段对话能在聊天界面和原生 CLI 之间切换

手机遥控：能下载手机app，出门远程遥控电脑上的agent干活

Bots：将自己的Agent订阅做成一个bot，在 Slack、Linear、GitHub 里 @ 它自动修 bug
