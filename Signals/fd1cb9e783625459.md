# v2.1.299

> Claude Code release: env var controls @ file mention context.

<h2>What's changed</h2>
<ul>
<li>Added <code>CLAUDE_CODE_DISABLE_FILE_MENTIONS</code> environment variable: Claude gets the paths of <code>@</code> file mentions to read with its file tools, not the files' contents</li>
<li>Added idle compaction in the terminal: a 200K+ token conversation left idle for about 54 minutes is compacted before its one-hour prompt cache expires, so your next message doesn't reprocess it all</li>
<li>Added <code>CLAUDE_CODE_IDLE_COMPACT_MIN_TOKENS</code> to change idle compaction's 200K-token minimum; <code>"idleCompaction": false</code> in settings.json turns it off
