This is an interesting test because most multi-agent systems today have some hierarchy or structure.

Agensh has no central orchestrator.

It coordinates parallel coding agents through a shared state instead of a central orchestrator.

Each agent gathers context, claims a sub-task, does the work, shares what it found, verifies the result, and merges it, all asynchronously through a shared workspace and a message channel.
