# google/skills: Agent Skills for Google products and technologies

> Agent Skills collection for Google products, agent-pattern relevant

This repository contains Agent Skills for Google products and technologies, including Google Cloud.
npx skills add google/skills
When prompted, select specific skills or all skills, the target agents to configure, and the installation scope (project or global).
If npx is not available in your environment, install
Node.js, which includes npm and npx.
To update previously installed skills to the latest versions, run the following command.
npx skills update
This command gives you an option to also remove obsolete skills.
This repo also bundles Google product plugins (Skills + MCP servers) for age
