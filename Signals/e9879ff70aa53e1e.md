# llm-anthropic 0.30

> Claude Sonnet 5.5 + token optimization features in LLM tool

<p><strong>Release:</strong> <a href="https://github.com/simonw/llm-anthropic/releases/tag/0.30">llm-anthropic 0.30</a></p>
        <p>In addition to Claude Sonnet 5.5, this release adds the ability to run <code>llm anthropic refresh</code> to refresh the list of Anthropic models directly from their API - which means I don't need to push a new release just to add support for a newly released model.</p>
<p>I also added an <code>llm anthropic count</code> command which can use their free token counting API to return a count of tokens that will be used by any prompt, before you send that prompt.<
