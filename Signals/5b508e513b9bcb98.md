# FaqFirebase/pi-desktop

> Desktop GUI wrapper for Pi coding agent.

Pi 的终端用腻了？社区已经有人开始给它搓各种 GUI 了🔥

最近翻了一圈 Pi 社区，发现几个挺有意思的项目，保留 Pi 原本的 Agent 能力，只是换一种更舒服的使用方式

1、Morse：VS Code + 浏览器双端 UI

https://t.co/bvamxZuJrZ

支持多项目、多 Session、图片粘贴，还能随时中断任务、切换模型。它直接调用 Pi 的 RPC 模式，复用原来的配置，不需要重新造一套 Agent

2、Pi Desktop：独立桌面工作台

https://t.co/WHfefVJD7f

把聊天、文件编辑、终端和 Git Diff Review 放到一个窗口里，支持 macOS、Windows 和 Linux，适合不想一直待在终端里的朋友

3、Pi Web：直接在浏览器里用 Pi

https://t.co/5FU8YxjWkp

复用本地 Pi 配置和 Session，可以在浏览器里继续之前的对话、运行任务、切换模型和查看项目文件

4、pi-ahp：把 Pi 接进 VS Code 的 Agent 界面

https://t.co/w8i6
