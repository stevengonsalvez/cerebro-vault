> Practitioner note on agents ignoring MCP; tool-use pattern

I build MCP into my apps. My own agents almost never use it.

My setup is simple. Each agent is a Claude Code session with its own project folder and a .env containing whatever keys it needs. I tell it to get something done. I don’t care how.

It almost never picks MCP.

Not because MCP is bad, but because of the connector step. In most setups, a human has to install and configure the connector before the agent can use it. The agent can’t do that part, so it stops and asks me to get up, go to the computer and click things.
