# Libghostty 1.0

> Terminal emulator library; core terminal tech, borderline

Mitchell Hashimoto
Libghostty 1.0
libghostty-vt 1.0 is here. libghostty is a
portable, high-performance C library for terminal emulation, extracted
directly from the core of Ghostty. The 1.0 release means both the library
itself and the C ABI are now stable.
A little over a year ago, I wrote that libghostty is coming. At the time, the Zig module had just been merged, the C API didn't exist, and nobody but Ghostty was a consumer.
