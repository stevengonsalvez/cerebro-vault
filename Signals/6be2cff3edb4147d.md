> CODING_STANDARDS agent feedback loop pattern, must-read

Tons of folks ask me "how do I create a CODING_STANDARDS.md file?"

My answer is that if you're using it right, it should only be empty for about 5 minutes.

Every meaningful thing your agent gets wrong should be noted into CODING_STANDARDS.

- Forget to implement dark mode?
- Forgot a validation rule?
- Used the wrong framework primitive?

Use /retro to fill it up, or modify it yourself.
