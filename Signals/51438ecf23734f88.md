> Claude Code agent-driven review process; direct coding-agent deep-dive

Claude writes ~90% of Claude Code’s code. Agents now do most of the code review, too.

The Claude Code team at Anthropic just published how their review process works:

• Before a PR opens: runnable checks, then a second agent reviews the diff with fresh context.
• On every PR: parallel agents find bugs, and separate agents vote on whether each finding is real.
• Security review and CI gate merging.
• Low-risk changes from trusted authors can merge without human approval. Higher-risk changes need one or two people.
• Merge queues, feature flags and staged releases help contain mistakes.
