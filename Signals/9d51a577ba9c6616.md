> Terminal-pane coding agent platform recommendation

RT @NixFred: If you are using @herdrdev, @orca_build or anything else that puts a coding agent in a terminal pane, check out @t3dotcodes .

It is open source, from @theo and @jullerino. It runs on the subscriptions you already have: Claude Code, Codex, Cursor, Grok Build, OpenCode, Antigravity.

It is a different idea from a multiplexer. There is no agent terminal. A server on your machine drives the agent. The desktop app, a browser or your phone shows the conversation.
