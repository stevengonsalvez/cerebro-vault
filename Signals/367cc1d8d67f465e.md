> T3 Code guest sharing; agent tool-pairing collaboration feature

New beta feature in T3 Code: "share with guest"

I'm so tired of copy pasting from a thread, sending it to a coworker, waiting for them to respond, screenshotting the context and sending it back to my agent.

Now I just send them a link.

It's a silly place to start, but I was heavily inspired by the Uber Eats/Doordash group order flow. If I send someone a link to my group order, they can add whatever they want, but ultimately I decide if the order goes through or not.
